# HARVEST TABLE

## 실제 게임 기능 기획서

> 확정되지 않은 수치와 세부 규칙은 `개발 중 결정`으로 표시한다.

## 1. 게임 진행 구조

### 1.1 기본 맵과 이동

- 좌우로 긴 기본 맵을 구성하며, 화면에는 맵의 일부만 표시한다.
- 건물은 집, 농사지, 목장, 광산, 뷔페 순서로 배치한다.
- 플레이어는 좌우 방향키로 이동한다.
- 플레이어의 이동에 따라 카메라와 맵이 함께 스크롤된다.
- 건물 앞에서 `Space` 키를 누르면 해당 건물에 입장한다.

### 1.2 건물별 시점과 조작

- 광산은 정면 시점(`front view`)을 유지한다.
- 농사지, 목장, 뷔페는 위에서 내려다보는 시점(`top view`)으로 전환한다.
- `top view`에서는 상하좌우 방향키를 사용한다.
- 건물 내부의 입구에서 `Space` 키를 누르면 기본 맵으로 돌아온다.

### 1.3 전체 게임 흐름

```text
자원 채집
  ↓
자원 판매·요리 제작·시설 업그레이드
  ↓
뷔페 운영 및 손님 응대
  ↓
수익 획득
  ↓
채집·생산·응대 자동화
  ↓
요리 5종을 각각 100개 이상 판매
```

## 2. 광산 시스템

### 2.1 광산 외부와 땅굴 입구

- 광산 외부는 기본 맵과 같이 좌우로 긴 맵으로 구성한다.
- 광물 종류에 따라 땅굴 입구를 배치한다.
- 땅굴 입구에서 `Space` 키를 누르면 땅굴 내부로 입장한다.
- 가까운 땅굴부터 낮은 등급의 광물을 배치한다.
- 게임 시작 시 맵 앞쪽의 땅굴은 기본 해금 상태로 설정한다.
- 해금되지 않은 땅굴 입구에는 나무판자를 X자로 배치해 닫힌 상태를 표시한다.
- 땅굴의 구체적인 해금 조건은 개발 중 결정한다.

```text
ㅁ - o - () - () - () - ,,,

출입구 - 상인 - 땅굴1 - 땅굴2 - 땅굴3 - ,,,
```

### 2.2 광물 종류와 배치

- 광물은 석탄, 철, 금으로 구성한다.
- 광물은 땅굴별로 종류와 등급을 구분한다.
- 기획 및 구현 단계에서는 필요에 따라 `광물1`, `광물2`, `광물3`으로 임시 표기할 수 있다.

```text
석탄 - 철 - 금
```

### 2.3 광산 상점과 장비

- 상인과 상호작용하면 광산 관련 아이템을 구매할 수 있다.
- 현재 채굴할 수 없는 광물과 관련된 아이템은 상점에 표시하지 않는다.
- 아이템의 세부 가격과 해금 조건은 미정 사항으로 관리한다.

| 아이템 | 기능 |
| --- | --- |
| 나무 곡괭이 | 기본 채굴 도구 |
| 돌 곡괭이 | 석탄 4개, 철 1개 채굴 |
| 철 곡괭이 등 | 이후 단계에서 추가 |
| 광부 1 | `[땅굴1]` 자동 채굴 +1 |
| `[땅굴2]` 입장권 | 땅굴 2 해금 |
| 광부 2 | `[땅굴2]` 자동 채굴 +1 |

- 곡괭이는 나무 곡괭이, 돌 곡괭이, 철 곡괭이 순서로 발전시킨다.
- 각 곡괭이는 땅굴별 채굴 가능 광물과 채굴 효율을 표시한다.
- `[땅굴2]` 표기는 추후 석탄 광산, 철 광산 등 실제 이름으로 변경할 수 있다.

#### 곡괭이 설명 예시

- 나무 곡괭이: 석탄을 2개씩 채굴한다.
- 돌 곡괭이: 석탄을 4개씩 채굴하고 철을 1개씩 채굴한다.

### 2.4 땅굴 내부와 채굴

- 땅굴 내부는 정면 시점에서 화면 이동 없이 고정된 맵을 사용한다.
- 입구, 플레이어 채굴 공간, 광부를 순서대로 배치한다.

```text
ㅁ - o - m - m - m - ,,,

땅굴 입구 - 플레이어 채굴 공간 - 광부 - 광부 - 광부 - ,,,
```

- 플레이어 채굴 공간의 바닥에는 해당 광물 이미지를 배치한다.
- 플레이어가 채굴 공간에 들어가면 해당 공간을 강조 표시한다.
- 채굴 공간에서 `Space` 키를 누르면 광물을 획득한다.
- 별도의 쿨타임은 없으며, 키 입력 1회를 채굴 트리거로 사용한다.
- 채굴 성공 확률이 별도로 존재하며, 채굴에 성공하면 자원을 획득한다.
- 광부는 곡괭이질 후 일정 시간 대기한 뒤 같은 행동을 반복한다.
- 광부는 5초마다 채굴을 시작하고 자원을 1회 수급한다.

## 3. 농사지 시스템

### 3.1 농사지 구조와 재배 공간

- 농사지에 입장하면 `top view`로 전환한다.
- 화면 중앙 하단에 입구를 배치하며, 퇴장할 때 사용한다.
- 입구 왼쪽에 상인을 배치해 농사지 관련 상품을 판매한다.
- 맵의 좌상단, 우상단, 우하단에 농작물 재배 공간을 배치한다.

```text
「 농작물 1              농작물 2ㄱ

ㄴ상점          입구      농작물 3」
```

- 해금된 농작물 재배 공간에만 씨앗을 심는다.
- 농작물마다 5×5칸의 재배 공간을 제공한다.
- 재배 공간 중앙에는 스프링클러를 설치한다.
- 스프링클러가 설치된 칸은 이동할 수 없다.

### 3.2 농작물과 성장

- 농작물은 밀, 감자, 딸기로 구성한다.
- 농작물의 해금 순서는 추후 결정한다.
- 농작물 칸 위에서 `Space` 키를 누르면 작물을 수확한다.
- 농작물은 수확한 뒤 2분이 지나면 다시 성장한다.

### 3.3 농사지 상점과 농부

#### 상인 판매 품목

| 아이템 | 기능 |
| --- | --- |
| 괭이 | 수확 시 획득량 증가 |
| 비료 | 성장에 필요한 시간 감소 |
| 농작물 2 해금 | 농작물 2 재배 가능 |

- 농부1은 농작물1 재배 공간을 무작위로 이동하며 발밑의 작물을 수확한다.
- 농부1은 기본적으로 최대 3명까지 고용할 수 있다.
- 농부는 괭이의 수확 효율에 영향을 받는다.
- 농부의 고용 비용과 자동 수확 주기는 추후 결정한다.

## 4. 목장 시스템

### 4.1 목장 구조

- 목장 맵은 농사지와 동일한 구조로 구성한다.
- 각 동물 구역은 울타리로 나누어 관리한다.
- 동물은 배치된 객체 수만큼 울타리 안을 자유롭게 이동한다.

| 위치   | 동물 |
| ------ | ---- |
| 좌상단 | 닭   |
| 우상단 | 소   |
| 우하단 | 돼지 |

### 4.2 동물 자원과 획득

- 각 울타리 안에서 `Space` 키를 누르면 해당 동물의 수에 따라 자원을 획득한다.
- 닭에서는 달걀을 획득한다.
- 소에서는 우유를 획득한다.
- 돼지에서는 버섯을 획득한다.
- 자원을 획득한 뒤 2분이 지나면 다시 획득할 수 있다.

### 4.3 목장 상점과 자동화

- 상인은 닭, 소, 돼지를 판매한다.
- 관리인을 배치하면 일정 시간마다 자원을 자동으로 수확한다.
- 사냥용 칼을 구매할 수 있다.
- 사냥용 칼을 보유한 상태에서 동물에게 `Space` 키를 누르면 해당 동물의 자원과 고기를 획득한다.
- 사냥용 칼은 1회용이며, 상호작용 1회마다 칼 1개와 동물 1마리가 감소한다.
- 교배 전문가는 같은 동물이 2마리 이상 있을 때 일정 시간마다 해당 동물 1마리를 추가한다.

## 5. 뷔페 시스템

### 5.1 뷔페 구조와 대기 줄

- 뷔페는 `top view`로 구성한다.
- 호텔 맵의 좌상단에 입구를 배치한다.
- 입구 바로 오른쪽에 계산대를 배치한다.
- 입장 손님과 결제 손님은 계산대를 기준으로 두 줄로 대기한다.
- 계산대 위쪽은 입장 손님, 아래쪽은 결제 손님 대기 공간으로 사용한다.

```text
「 입구   계산대  (상호작용 공간)          상인ㄱ
              계산대 (포스기 또는 금고)   요리사

요리1  요리2  요리3
요리4  요리5  ,,,

의자  식탁  의자 / ,,,

,,, / ,,,
ㄴ                                          」
```

### 5.2 뷔페 상점과 시설

- 상인은 시설 업그레이드 관련 아이템만 판매한다.

#### 식탁 및 의자 구매 규칙

- 식탁과 의자는 상점에서 구매한다.
- 다음 식탁을 구매하려면 의자 2개를 먼저 구매해야 한다.
- 여유 식탁이 없으면 의자를 구매할 수 없다.

| 항목            | 비용 또는 재료 | 효과                                   |
| --------------- | -------------- | -------------------------------------- |
| 의자 업그레이드 | 광물 × n개    | 손님이 오래 머무를 확률 증가           |
| 식탁 업그레이드 | 추후 결정      | 손님의 식사 속도 증가                  |
| 장식 업그레이드 | 추후 결정      | 결제 금액 증가, 손님 입장 확률 증가 등 |

### 5.3 요리사와 요리 제작

- 요리사는 요리 제작에 필요한 재료를 요구한다.
- 플레이어는 요리사와 상호작용해 요리별 제작 메뉴를 확인한다.
- 요리별 제작 버튼은 뷔페 상점이 아닌 요리사에게 제공한다.
- 재료가 충분하면 요리를 즉시 제작한다.
- 제작 횟수만큼 요리가 요리 공간에 생성된다.
- 제작한 요리는 손님이 뷔페에서 선택해 먹는다.

#### 요리 목록

| 단계 | 요리 | 재료 | 역할 |
| --- | --- | --- | --- |
| 초반 | 감자튀김 | 감자 | 기본 요리 |
| 초반 | 계란빵 | 밀, 달걀 | 농사지와 목장 자원 사용 |
| 초반 | 딸기 디저트 | 딸기, 우유 | 기본 디저트 |
| 중반 | 버섯 수프 | 버섯, 우유 | 목장 자원을 활용하는 중급 요리 |
| 후반 | 고기 스테이크 | 고기, 감자 | 높은 판매 수익을 기대하는 요리 |

- 초반에는 감자튀김, 계란빵, 딸기 디저트를 제작할 수 있다.
- 중반에 버섯 수프를 해금한다.
- 후반에 고기 스테이크를 해금한다.
- 요리별 판매 가격과 손님 만족도는 미정 사항으로 관리한다.
- 광물은 요리 재료가 아니라 주방 시설, 식탁, 의자, 장식 업그레이드에 사용한다.

### 5.4 손님 이동과 응대

1. 손님이 기본 맵 외곽에서 생성된다.
2. 손님은 한쪽 방향으로 이동한다.
3. 일정 확률로 뷔페 입구를 통해 뷔페에 입장한다.
4. 입장 손님은 입장 대기 줄을 거쳐 계산대 앞 상호작용 공간으로 이동한다.
5. 플레이어가 계산대 위쪽 상호작용 공간에서 `Space` 키를 누르면 손님을 받는다.
6. 손님은 아래쪽으로 이동해 요리를 선택하고 의자로 이동한다.
7. 손님은 무작위 횟수만큼 요리를 추가로 가져와 먹는다.
8. 식사를 마친 손님은 결제 줄로 이동한다.
9. 플레이어가 계산대 아래쪽에서 `Space` 키를 누르면 계산을 처리한다.
10. 계산을 마친 손님은 입구로 이동해 뷔페를 나간다.
11. 손님은 기본 맵 외곽을 통해 화면에서 완전히 퇴장한다.

## 6. 저장 및 불러오기

- 기본 맵의 집 앞에서 `Space` 키를 누르면 저장 및 불러오기 메뉴를 표시한다.
- 저장 및 불러오기 시 문자열을 입력받아 플레이어별 저장 데이터를 구분한다.
- 저장 슬롯은 총 5개를 제공한다.
- 5개 슬롯이 모두 사용 중인 상태에서 새로 저장하면 기존 저장 이름 5개를 표시한다.
- 플레이어가 삭제할 저장 이름을 선택하면 해당 저장 데이터를 삭제하고 새 데이터를 저장한다.

### 6.1 저장 데이터 구성 초안

- 저장 데이터는 저장에 사용한 이름, 광산, 농사지, 목장, 뷔페 순으로 줄을 구분한다.
- 각 줄에서는 필요한 데이터를 변수별로 공백으로 구분해 저장한다.

## 7. 최종 목표와 엔딩

- 요리 5종을 각각 100개 이상 판매한다.
- 별도로 정한 금액 이상을 보유하면 엔딩 조건을 달성한다.
- 필요한 보유 금액은 개발 중 결정한다.
- 플레이어는 목표를 달성하는 과정에서 수동 작업을 자동화한다.
- 엔딩 달성 시 완료 화면과 플레이 결과를 표시한다.

### 7.1 엔딩 결과 화면

엔딩 결과 화면에는 다음 정보를 표시한다.

- 총 플레이 시간
- 광산에서 채집한 자원의 총 개수
- 농사지에서 수확한 농작물의 총 개수
- 목장에서 획득한 자원의 총 개수
- 고용한 직원 수
- 분당 수익

마지막 줄에는 플레이어의 최종 분당 수익을 강조해 표시한다.

## 8. 개발 중 결정 사항

### 8.1 경제 및 해금

- 각 아이템과 업그레이드의 가격
- 엔딩 달성에 필요한 보유 금액
- 땅굴의 구체적인 해금 조건
- 농작물의 해금 순서와 해금 조건
- 광산 채굴 성공 확률
- 식탁 및 장식 업그레이드의 가격과 세부 효과

### 8.2 손님 및 직원

- 손님 입장 확률과 행동 시간
- 직원 및 관리인의 고용 비용
