# 목장(랜치) 시스템 개발 PRD

## 1. 문서 목적

이 문서는 `PRD.md` 5단계(목장 시스템)와 `PRE_PRD2.md` 4장의 목장 규칙을 기준으로, 목장 시스템의 개발 범위·구현 구조·완료 기준을 정리한 개발용 PRD다.

- 개발 환경: Python, `pico2d`
- 대상: 목장 장면 전체 (맵, 동물 구역, 자원 획득, 상점, 자동화)
- 선행 조건: `PRD.md` 0~4단계 완료 (게임 루프, 기본 맵·건물 입장, 자원/돈 데이터, 광산·농사지 시스템)
- 용어: 기획서 표현을 따르되 본 문서에서는 **목장**으로 통일한다.

## 2. 기준 문서와 우선순위

1. `PRE_PRD2.md` 4장: 목장 최신 세부 규칙
2. `PRD.md` 5단계: 구현 범위와 완료 기준
3. `SPRITE_PRD.md` 8장: 필요한 이미지 목록
4. `농장_PRD.md`: 동일 패턴(상점·자동화·타이머·커밋 규칙)의 구현 참조

문서 간 충돌 시 `PRE_PRD2.md`를 우선한다.

## 3. 핵심 규칙

### 3.1 시점과 맵 구조

- 목장 입장 시 `top view`(상하좌우 방향키)로 전환한다. (`PRD.md` 4.2표 참조)
- 목장 맵은 **농사지와 동일한 구조**로 구성한다 (`ranch_background.png` 880×880, 농사지와 동일 스케일).
- **중앙 상단에 입구**(기본 맵 퇴장), **좌측 상단에 판매 상인**을 배치한다 (농사지 배치 원칙 상속).

### 3.2 동물 구역과 울타리

- 각 동물 구역은 **울타리**로 나누어 관리한다 (`fence_tile`, `fence_gate`).
- **좌측 상단은 상인**이고, 동물 구역은 나머지 3모서리에 **티어 순서대로** 배치한다.
  (구역 위치는 `PRE_PRD2.md` 4.1 대신 **본 규칙을 우선** 적용한다.)

```text
「 상인     입구        동물 1

             동물 2     동물 3 」
```

| 구역 | 티어 | 동물 | 자원 | 위치 |
| --- | --- | --- | --- | --- |
| 동물 1 | 1티어 | 닭 (chicken) | 달걀 (egg) | 우상단 |
| 동물 2 | 2티어 | 소 (cow) | 우유 (milk) | 좌하단 |
| 동물 3 | 3티어 | 돼지 (pig) | 버섯 (mushroom) | 우하단 |

- 티어 순서는 **닭 → 소 → 돼지**이며, 해금 티어가 바뀌면 배치 순서만 조정한다.
- 동물은 **배치된 마릿수만큼** 울타리 안을 자유롭게 이동한다 (농부와 같은 무작위 이동 패턴).
- 동물 이동 속도는 **플레이어 속도의 절반**이다 (`농장_PRD` 4절 속도 기준 — 동물 = 0.5배).

### 3.3 동물 자원과 획득

- 해당 울타리 안에서 `Space` 키를 누르면 **구역 내 동물 수에 따라** 자원을 획득한다 (예: 닭 3마리 → 달걀 3).
- 자원 획득 후 **2분이 지나면** 다시 획득할 수 있다 (구역 단위 쿨다운, `REGROW_SECONDS`와 동일 패턴).
- **각 구역의 우측 하단에 재획득 타이머**를 표시한다: 획득 직후 남은 시간(MM:SS)을 카운트다운하고, 재획득이 가능해지면 숨긴다 (텍스트 표시 — 이미지 불필요).
- 획득 시 광산/농사지와 동일한 상승 텍스트 알림을 표시한다 (이펙트 이미지 없이 텍스트로 대체).

### 3.4 사냥 (사냥용 칼)

- `hunting_knife`를 보유한 상태에서 동물 구역에 `Space`를 누르면 **해당 동물의 자원과 고기를** 함께 획득한다.
- **1회용**: 상호작용 1회마다 **칼 1개와 동물 1마리가 각각 감소**한다.
- 획득하는 고기는 동물별로 구분한다: 닭 → 닭고기(chicken), 소 → 소고기(beef), 돼지 → 돼지고기(pork).
- 칼이 없으면 자원 획득만 진행된다 (3.3 규칙).

### 3.5 목장 상점

- 상인은 **닭·소·돼지**(동물), **사냥용 칼**, **관리인**, **교배 전문가**를 판매한다.
- 상점 UI는 농사지 상점(`shop.py`의 페이지/클릭/아이콘 구조)을 그대로 재사용한다.
- **동물 판매**(보유 동물 처분)도 제공한다 (판매 방식·가격은 개발 중 결정, 광산 판매 상인 패턴 재사용 후보).

**결정값 표** (개발 중 확정, 아래 7장)

| 상품 | 기능 |
| --- | --- |
| CHICKEN / COW / PIG | 해당 동물 +1마리 (구역 한계는 개발 중 결정) |
| HUNTING KNIFE | 1회용 사냥 칼 +1 |
| CHICKEN / COW / PIG MANAGER | 해당 구역 자동 수확 관리인 고용 (구역당 3명) |
| BREEDER | 교배 전문가 고용 |

### 3.6 자동화 (8단계와 연결)

- **관리인**: 고용한 구역에서 **일정 시간마다** 자원을 자동으로 수확한다 (농부와 같은 모션→결과 적용 패턴, 주기·비용은 개발 중 결정).
- **교배 전문가**: **같은 동물이 2마리 이상** 있을 때, 일정 시간마다 해당 동물 1마리를 추가한다 (전역 주기 틱).
- 자동화는 농사지와 동일하게 **장면 밖에서도 진행**된다 (`auto_npc` 전역 update 패턴).
- 관리인·교배 전문가·동물 모두 `auto_npc.py` 모듈의 확장 대상이다.

### 3.7 그 외 설정

**기본값 (테스트 후 조정 가능 — 농장 패턴의 확정값)**

| 항목 | 설정값 |
| --- | --- |
| 동물 구역 상한 | 구역당 **10마리** (광부 패턴, 상점에 `n/10` 표시) |
| 시작 시 보유 동물 | **닭 1마리** (동물1 구역에서 바로 상호작용 가능) |
| 자원 재획득 쿨다운 | **120초 확정** — 사냥(칼) 획득도 동일 쿨다운 적용 |
| 사냥 산식 | 자원은 동물 수만큼 + **고기 1개** 추가 (칼 1·동물 1 감소는 3.4) |
| 플레이어 상호작용 | 농사지와 동일한 **2초 작업 모션 후 결과 적용** (자원·고기 지급과 칼·동물 감소 모두 모션 종료 시점) |
| 관리인 | 구역당 **최대 3명** (농부 패턴), 자동 수확 주기 **5초** |
| 교배 전문가 | **전체 최대 1명**, 주기 **60초**, 1회에 +1마리 (동물 상한 10이 자연 상한) |
| 상점 구성 | 좌상단 상인 1명이 **구매 + 판매 페이지를 동시 제공** (농사지의 분리 상인 대신) |
| 판매 페이지 | 자원 6종 판매 + **동물 판매** (동물 판매가는 구매가의 절반 기준, 수치는 조정 가능) |
| 동물 0마리 구역 | `Space` 무응답, 타이머 숨김 |
| 타이머 표시 | 구역 사각형 **우측 하단 내측**, `MM:SS` 카운트다운, 작은 글씨(14px) 회색 |

**코드 연동 설정**

- `shop.item_image`에 자원 6종(`egg`·`milk`·`mushroom`·`chicken`·`beef`·`pork`) 매핑을 등록한다 → 상점·인벤토리에서 자동으로 아이콘 표시.
- 인벤토리 표시 범위: 자원은 COLLECTIBLES 탭(자동), 칼은 TOOLS 탭에 이름 표시(보유 수량은 상점에서 `x n`으로), 동물 수는 상점·목장 화면에만 표시 (농부 표시 방식과 일관).

## 4. 데이터 구조

농사지와 같은 패턴으로 `game_state` + `auto_npc`에 추가한다.

```python
# game_state.py
collected_items = { ...,            # 기존 자원에 추가
    "egg": 0, "milk": 0, "mushroom": 0,
    "chicken": 0, "beef": 0, "pork": 0,   # 고기 3종 (아이콘 파일명과 동일 키)
}
animal_counts = {"chicken": 0, "cow": 0, "pig": 0}   # 구역별 동물 마릿수
animal_cooldowns = {}      # 구역 -> 마지막 자원 획득 시각 (2분 쿨다운)
hunting_knives = 0         # 보유 사냥용 칼
# 관리인/교배 전문가 보유 상태는 농부 고용(auto_npc) 패턴으로 관리

# auto_npc.py 확장
# - 동물 상태(무작위 이동, 4프레임 64x64 시트 — 농부와 동일 렌더 구조)
# - 관리인 자동 수확(모션→결과 적용), 교배 전문가 주기 틱
```

- 시간 처리는 전부 `pico2d.get_time()` 경과 시간 기반 (프레임 무관).
- 자원 키는 **아이콘 파일명과 동일**하게 유지한다 (`assets/item/egg.png` 등 → 인벤토리 아이콘 자동 매핑 `shop.item_image`에 등록).

## 5. 구현 단계

각 단계는 직전 단계의 완료 기준을 통과한 뒤 진행하며, **단계마다 점진적으로 커밋**한다. 규칙은 `농장_PRD` 5.0과 동일하다.

- **커밋 규칙**: 한 커밋에 한 가지 기능 / 커밋 전 스모크 테스트 통과 / 콜론 뒤 제목은 한글 / PRD 변경은 같은 커밋에 / 새 이미지와 로딩 코드 동시 커밋
- **분기**: 별도 `feature/ranch` 브랜치에서 진행하고, R 단계 완료 시점에 main으로 머지

**커밋 단위 (세분화)**

| # | 커밋 메시지 예시 | 포함 내용 |
| --- | --- | --- |
| R1-1 | `r1: 목장 배경과 카메라 경계 추가` | ranch_background 880×880, top view 씬 전환 |
| R1-2 | `r1: 목장 입구와 상인 배치` | 입구(중앙 상단)·판매 상인(좌상단), Space 퇴장/상점 |
| R2-1 | `r2: 동물 구역 데이터와 울타리 렌더링` | 3구역(닭좌상·소우상·돼지우하), fence 렌더 |
| R2-2 | `r2: 동물 배치와 구역 내 이동` | 동물 마릿수 배치, 울타리 안 무작위 이동(속도 0.5배) |
| R3-1 | `r3: Space로 동물 자원 획득` | 동물 수 기반 지급 + 상승 알림 |
| R3-2 | `r3: 자원 재획득 2분 쿨다운` | 구역 단위 쿨다운, 중복 획득 방지, 구역 우측 하단 타이머 표시 |
| R3-3 | `r3: 사냥용 칼로 자원과 고기 획득` | 칼 보유 시 분기, 칼1·동물1 감소 |
| R4-1 | `r4: 목장 상점 동물 판매 추가` | 닭/소/돼지 구매(동물 수 증가), 구역 상한 10마리 검증·`n/10` 표시 |
| R4-2 | `r4: 사냥용 칼 판매 추가` | 칼 구매, 중복/잔액 검증, 보유 수량 표시 |
| R4-3 | `r4: 목장 상점 판매 페이지 추가` | 자원 6종 + 동물 판매(판매가 절반), 광산 판매 페이지 패턴 재사용 |
| R5-1 | `r5: 관리인 자동 수확 추가` | 고용·구역 한계·전역 주기 틱·모션→결과 |
| R5-2 | `r5: 교배 전문가 동물 번식 추가` | 2마리 이상 조건, 주기마다 +1 |

### R1. 목장 맵과 입장·퇴장 — `top view` 4방향 이동(농사지와 동일), 입구·상인 배치

**완료 기준**: 기본 맵↔목장 입장/퇴장 정상, 4방향 이동·경계 유지, 상인 앞에서 상점 열림

### R2. 동물 구역과 이동

**완료 기준**: 3구역 울타리 시각 구분, 동물은 마릿수만큼 배치, 구역 밖으로 벗어나지 않음, 속도 = 플레이어 절반

### R3. 자원 획득과 사냥

**완료 기준**: 구역별 올바른 자원 지급(닭→달걀 등), 재획득 전 중복 획득 불가, 칼 사용 시 칼·동물 각 1개 감소, 칼 없으면 자원만 획득

### R4. 목장 상점

**완료 기준**: 조건 미달/잔액 부족/중복 구매가 거부 메시지와 함께 차단, 구매 즉시 동물 수·칼 수 반영, 인벤토리에 아이콘 표시

### R5. 자동화

**완료 기준**: 관리인은 고용 구역에서만 자동 수확, 교배는 2마리 이상일 때만 발생, 장면 밖에서도 진행, 자원·동물 수량이 음수가 되지 않음

## 6. 완료 기준 (PRD.md 5단계 요약)

- 동물 구역별로 올바른 자원을 얻는다.
- 자원 재획득 전에는 중복 획득할 수 없다.
- 사냥용 칼 사용 시 칼과 동물이 각각 1개씩 감소한다.
- 교배 조건을 충족하면 동물이 추가된다.

## 7. 개발 중 결정 사항

기능 규칙·상한·주기는 3.7에 확정되어 있으며, 남은 미정 항목은 다음과 같다.

- 동물·관리인·교배 전문가·사냥용 칼의 **구매 비용**과 동물 **판매 가격 수치** (절반 기준은 확정)
- 고기의 **별도 판매가** (자원 판매 페이지 확정, 가격 미정)
- 구역·울타리의 **정확한 좌표값** (농사지 레이아웃 패턴으로 구현 시 확정)
- 결과 화면용 통계에 들어갈 목장 수치의 명칭

## 9. 테스트 체크리스트

- [ ] 목장 입장 → 상하좌우 이동 → 입구 퇴장
- [ ] 상인(좌상)·동물1 닭(우상)·동물2 소(좌하)·동물3 돼지(우하) 티어 순서 배치와 울타리 시각 구분
- [ ] 각 구역 우측 하단 타이머가 재획득까지 카운트다운되고 준비 시 숨김
- [ ] 동물 구역 상한 10마리 초과 구매 거부, 상점에 `n/10` 표시
- [ ] 동물은 마릿수만큼 배치되고 구역 밖으로 나가지 않음 (속도 = 플레이어의 절반)
- [ ] Space로 구역별 올바른 자원 획득 (닭 3마리 → 달걀 3)
- [ ] 재획득 전(2분 쿨다운) 중복 획득 불가
- [ ] 사냥용 칼 보유 시 자원+고기 동시 획득, 칼 1·동물 1 감소 / 칼 없으면 자원만
- [ ] 상점 구매: 잔액 부족/중복/한계 거부 메시지
- [ ] 인벤토리에 달걀·우유·버섯·고기 아이콘 표시
- [ ] 관리인 자동 수확이 고용 구역에서만 동작, 교배는 2마리 이상에서만
- [ ] 목장 밖(기본 맵)에서도 자동화 진행
- [ ] 자원·동물·돈 수량이 음수로 내려가지 않음
