# 2차 발표 PDF 제작 요구사항

## 1. 발표 기본 정보

- 발표 주제: 자원 채집과 자동화가 결합된 2D 뷔페 경영 게임
- 개발 환경: Python, `pico2d`
- 장르: 2D 타이쿤·경영 게임
- 발표 영상 분량: 정확히 1분 30초
- 발표 PDF 분량: **3페이지**
- 발표 목적: 게임 설명과, 1차 개발 일정 대비 현재 진행 상황·기획 변경 내용을 전달한다.
- 구성 기준: `발표2_PRE_PRD.md` 요구사항 참조

## 2. 발표 핵심 메시지

> 광산, 농장, 목장, 뷔페에서 직접 채집·운영하여 자동화해 나가는 게임이다. 1차 계획 대비 현재까지의 진행 상황과 기획 변경 내용을 공유한다.

발표를 통해 다음 내용을 명확하게 전달한다.

- 게임이 무엇이고 어떤 재미를 주는지
- 1차 개발 일정 대비 현재까지의 진행 상황
- 게임 기획 변경 내용과 변경 이유

## 3. PDF 3페이지 구성

### 1페이지. 제목 

기존 1차 발표 PPTX에서 그대로 사용

### 2페이지. 게임 간단 설명

- 광산, 농장, 목장, 뷔페에서 **직접 채집 & 운영 → 자동화**를 해 나간다는 점을 설명한다.
- 자원 채집 시설과 뷔페의 관계를 간단한 그림으로 표현한다.

```text
광산·농장·목장에서 자원 채집 → 뷔페 운영 (요리 제작·손님 응대) → 수익 획득 → 자동화
```

- 최종 목표: 요리 5종을 각각 100개 이상 판매

### 3페이지. 계획 대비 현재 진행 상황

1차 계획한 개발 일정 대비, 현재까지의 진행 상황을 상세히 설명한다.

#### 진행 상황

| 구분             | 항목                           | 현재 진행률 | 진행 내용             |
| ---------------- | ------------------------------ | ----------: | --------------------- |
| 자원 획득소 개발 | 광산                           |      약 80% | 채굴·광물 획득 구현  |
|                  | 농장                           |          0% | 미진행                |
|                  | 목장                           |          0% | 미진행                |
| 뷔페 개발        | 뷔페                           |          0% | 미진행                |
| 자동화           | 자동화 관련 내용               |          0% | 미진행                |
| 손님             | 손님 관련 내용                 |          0% | 미진행                |
| UI·이미지 제작  | UI (인벤토리, 상점, 돈)        |      약 20% | 핵심 UI 일부 제작     |
|                  | 이미지 (기본맵, 광산, 광물 등) |      약 20% | 핵심 리소스 일부 제작 |
| 밸런스 조정      | 밸런스 조정                    |          0% | 미진행                |



## 4. 1분 30초 발표 시간 배분

| 구간           | 시간 | 발표 내용                                  |
| -------------- | ---: | ------------------------------------------ |
| 1페이지        |  5초 | 제목과 게임 한 줄 소개                     |
| 2페이지        | 10초 | 게임 설명과 핵심 플레이 흐름               |
| 3페이지        | 30초 | 개발 계획 대비 진행 상황 및 기획 변경 내용 |
| 게임 실행 화면 | 45초 | 구현된 부분 실행 및 설명                   |

총 발표 시간은 **90초**로 맞춘다.

## 5. 시각 자료 요구사항

- 한 페이지에 핵심 메시지를 하나만 배치한다.
- 긴 문장보다 아이콘, 흐름도, 표를 우선 사용한다.
- 자원 채집 → 뷔페 운영 → 자동화의 흐름이 반복해서 보이도록 구성한다.
- 실제 구현 전인 기능은 완성된 화면처럼 표현하지 않고 기획 또는 예시로 표시한다.
- 3페이지는 진행률 표로 압축해 현재 상태를 한눈에 들어오게 구성한다.
- 진행률은 현재 실제 구현 상태와 일치하도록 작성한다.
- 발표 PDF에는 평가와 직접 관련 없는 세부 설명을 과도하게 넣지 않는다.
