# 1차 발표 PDF 제작 요구사항

## 1. 발표 기본 정보

- 발표 주제: 자원 채집과 자동화가 결합된 2D 뷔페 경영 게임
- 개발 환경: Python, `pico2d`
- 장르: 2D 타이쿤·경영 게임
- 발표 영상 분량: 정확히 1분 30초
- 발표 PDF 분량: 10페이지 이내
- 발표 목적: 게임의 방향, 핵심 재미, 구현 가능성, 개발 계획을 전달한다.

## 2. 발표 핵심 메시지

> 직접 자원을 채집해 작은 뷔페를 운영하고, 시설을 업그레이드해 생산과 손님 응대를 자동화하는 게임이다.

발표를 통해 다음 내용을 명확하게 전달한다.

- 무엇을 운영하는 게임인지
- 플레이어가 어떤 행동을 반복하는지
- 자원과 업그레이드가 어떻게 연결되는지
- 자동화가 어떤 재미와 성취감을 주는지
- 제한된 규모로 실제 구현할 수 있는지

## 3. 슬라이드 구성

### 1페이지. 표지

- 게임 제목
- 2D 타이쿤·경영 게임
- 이름, 학번
- 한 줄 소개

### 2페이지. 게임 소개

- 작은 뷔페를 운영하는 게임이라는 점을 설명한다.
- 플레이어가 자원을 채집하고 메뉴와 시설을 발전시킨다는 내용을 보여준다.
- 광산, 농장, 목장과 뷔페의 관계를 간단한 그림으로 표현한다.

### 3페이지. 게임 플레이 흐름

다음 순환 구조를 한눈에 보여준다.

```text
자원 채집 → 자원 교환·메뉴 제작 → 손님 응대 → 수익 획득 → 시설 업그레이드
```

### 4페이지. 자원 채집 시설

| 시설 | 주요 자원 | 사용처 |
| --- | --- | --- |
| 광산 | 광물 | 그릇, 집게, 의자, 식탁, 장식 |
| 농장 | 채소, 과일 | 샐러드, 과일 디저트 |
| 목장 | 달걀, 우유, 육류 등 | 스테이크, 케이크, 아이스크림 |

- 채집 시설은 광산, 농장, 목장 세 종류로 제한한다.
- 같은 레벨의 시설은 비슷한 수익 효율을 갖도록 밸런스를 조정한다.

### 5페이지. 뷔페 운영과 손님 흐름

- 손님 입장
- 플레이어가 클릭해 손님을 받음
- 손님이 뷔페를 이용하고 내부를 이동함
- 손님이 계산대로 이동함
- 플레이어가 클릭해 계산을 처리함

추후 직원 업그레이드를 통해 손님 응대와 계산을 자동화한다.

### 6페이지. 핵심 재미

- 초반에는 직접 채집하고 손님을 응대한다.
- 획득한 자원과 돈으로 시설을 업그레이드한다.
- 생산량과 수익이 증가한다.
- 자동화가 진행되면서 플레이어의 수동 조작이 줄어든다.
- 손님과 직원이 스스로 업무를 처리하는 모습을 보며 성취감을 얻는다.

### 7페이지. 구현 가능성

- 핵심 재화: 자원과 돈
- 채집 시설: 3종
- 손님 행동: 입장, 이용, 계산
- 핵심 업그레이드: 클릭 효율, 자원 생산, 손님 응대 자동화
- 초기 메뉴와 업그레이드 단계는 적은 수로 제한한다.
- 구현 상황에 따라 세부 메뉴와 시설 수를 조정한다.

### 8페이지. 개발 계획

1. 자원 채집과 기본 재화 시스템 구현
2. 자원 교환 및 메뉴 제작 구현
3. 클릭 효율과 자동화 업그레이드 구현
4. 손님 이동과 계산 상호작용 구현
5. 시설·직원 시스템과 UI 구현
6. 밸런스 조정 및 발표 영상 제작

### 9페이지. 기대 효과 및 마무리

- 채집부터 운영 자동화까지 단계적인 성장 구조를 제공한다.
- 제한된 시설과 콘텐츠로 완성 가능성을 확보한다.
- 핵심 재미인 성장과 자동화를 짧은 플레이 안에 보여준다.
- 질문 및 마무리 인사를 전달한다.

## 5. 시각 자료 요구사항

- 한 페이지에 핵심 메시지를 하나만 배치한다.
- 긴 문장보다 아이콘, 흐름도, 표를 우선 사용한다.
- 자원 채집 → 뷔페 운영 → 자동화의 흐름이 반복해서 보이도록 구성한다.
- 실제 구현 전인 기능은 완성된 화면처럼 표현하지 않고 기획 또는 예시로 표시한다.
- 발표 PDF에는 평가와 직접 관련 없는 세부 설명을 과도하게 넣지 않는다.
