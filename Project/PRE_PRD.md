## 게임 기획

### 어떤 게임을 만들 것인가?

- 플레이어가 직접 자원을 채집하는 작은 뷔페를 운영한다.
- 처음에는 직접 클릭해 자원을 채집하고, 획득한 자원과 돈으로 시설을 업그레이드한다.
- 업그레이드를 통해 클릭 효율을 높이거나 자원 생산을 자동화한다.
- 자원은 돈으로 교환하거나 뷔페 운영에 필요한 재료로 사용한다.

#### 자원 채집 시설

| 시설 | 주요 자원                 |
| ---- | ------------------------- |
| 광산 | 종류별 광물               |
| 농장 | 채소와 과일               |
| 목장 | 달걀, 양털, 우유, 육류 등 |

- 각 채집 시설을 업그레이드해야 더 높은 단계의 자원을 획득할 수 있다.
- 같은 레벨의 채집 시설은 비슷한 수준의 수익 효율을 내도록 밸런스를 조정한다.
- 업그레이드에는 돈과 해당 채집 시설의 자원을 함께 사용한다.
- 모든 채집 시설을 발전시켜야 하므로 특정 시설에만 의존하지 않도록 설계한다.

#### 뷔페 운영

- 광산 자원은 그릇, 집게, 의자, 식탁, 건물 외관과 내부 장식 등 시설 업그레이드에 사용한다.상
- 농장과 목장 자원은 메인 메뉴와 디저트 제작 재료로 사용한다.
- 농장 재료로 샐러드와 과일 디저트 등을 제작한다.
- 목장 재료로 스테이크, 케이크, 아이스크림 등을 제작한다.
- 메뉴와 시설을 단계적으로 확장해 뷔페의 수익을 높인다.

#### 손님 흐름

- 손님이 입장하면 클릭해 손님을 받는다.
- 손님은 일정 시간 동안 뷔페 내부를 이용하거나 돌아다닌다.
- 이용을 마친 손님은 계산대로 이동하며, 플레이어가 클릭해 계산을 처리한다.
- 이후 손님 응대와 계산을 자동화하는 직원 업그레이드를 추가할 수 있다.

### 핵심 재미는 무엇인가?

- 초반에는 플레이어가 직접 자원을 채집하고 손님을 응대하며 뷔페를 성장시킨다.
- 광산, 농장, 목장을 발전시키면서 재료 생산량과 수익이 점점 증가한다.
- 점차 생산과 손님 응대가 자동화되어 운영 효율이 높아진다.
- 손님과 직원이 플레이어의 직접 조작 없이 업무를 처리하는 모습을 보며 성취감을 느낀다.

### 구현 가능한 규모인가?

- 핵심 시스템을 자원 채집, 자원 교환, 업그레이드, 자동화로 제한한다.
- 채집 시설은 광산, 농장, 목장 세 종류로 제한한다.
- 초기 메뉴와 업그레이드 단계는 적은 수로 구성해 개발 범위를 관리한다.
- 손님과 직원의 행동은 입장, 이용, 계산 등 핵심 흐름만 구현한다.
- 세부 메뉴, 시설 수, 업그레이드 단계는 개발 일정에 따라 조정한다.

### 어떤 계획으로 개발할 것인가?

1. 자원 채집과 기본 재화 시스템을 구현한다.
2. 자원과 돈의 교환 시스템을 구현한다.
3. 클릭 효율 및 자동화 업그레이드를 추가한다.
4. 시설, 손님, 직원의 기본 상호작용을 추가한다.
5. 수익 증가와 자동화 과정을 확인할 수 있도록 UI와 피드백을 구현한다.
6. 콘텐츠 규모와 완성도를 점검한 뒤 발표용 플레이 영상을 제작한다.
